# Application fonts

Space Grotesk and Manrope are bundled variable fonts loaded with `next/font/local`.
Keeping them in the repository removes Google Fonts downloads from production
builds while retaining the existing display and body font families.

Original files from Google's official fonts repository:

- https://github.com/google/fonts/tree/main/ofl/spacegrotesk
- https://github.com/google/fonts/tree/main/ofl/manrope

Each family is distributed under the SIL Open Font License 1.1. Its license and
copyright notice are included alongside the unmodified font file.
